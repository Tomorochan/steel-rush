# STEEL RUSH — браузерная танковая гонка

Открытый прототип аркадных гонок на девяти дизельпанковских танках по трассе «Песчаный котёл».

- 3 фракции: СССР, Германия и США
- 9 низкополигональных танков
- 3D-трасса с объездами и ограничителями
- ИИ-соперники, медали-усиления, стрельба и форсаж
- Браузерная сборка WebGL2

## Публикация

GitHub Actions собирает оригинальные процедурные модели, трассу и игровую веб-версию из исходников в `bundle/part_*.b64` и развёртывает их через GitHub Pages.

При успешной публикации адрес игры: https://tomorochan.github.io/steel-rush/

Важное уточнение: версия 0.9 работает на временном WebGL2-рендерере, а не на окончательной архитектуре PlayCanvas. Инструкции для разработчиков и исходники доступны внутри упакованного исходного комплекта.

Лицензирование: самостоятельно созданные экспериментальные 3D-модели, без извлечения ресурсов коммерческих игр.

Тесты игровых механик выполняются в GitHub Actions перед публикацией. Подробные изменения — в `CHANGELOG_RU.md`.


## Версия 1.1 — выставочный ангар

В главном меню появилась кнопка **«ОСМОТР ТАНКОВ В 3D»**. Она открывает отдельную сцену с выставочным стендом, где можно спокойно осмотреть все девять моделей танков, не начиная гонку.

- Перетаскивайте мышь по центральной области, чтобы вращать камеру вокруг танка.
- Колёсико мыши приближает и отдаляет модель.
- Q / E, стрелки внизу или список слева переключают танки.
- Можно включить автоворот камеры и демонстрационное вращение башни.
- Справа доступны класс, характеристики, фракционная эмблема и цвет маркировки.
- Кнопка **«ВЫБРАТЬ И В ГОНКУ»** запускает заезд на выбранной машине.

Осмотр использует те же GLB-модели, что и гоночный режим. Весь модуль находится в updates/showroom.js и подключается автоматически в GitHub Actions.
